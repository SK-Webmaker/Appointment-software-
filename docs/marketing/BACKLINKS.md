# Backlinks and launch kit (for the owner)

Links from other trusted sites raise kairobookings.com's authority. That decides
how fast Google crawls our pages and how high it ranks them. Search Console
still shows pages as "Discovered – currently not indexed": that's a young site
with too few links pointing at it. Everything here is free. Each one needs an
account in your name, so it can't be automated from here. Do one or two a day.

**Rules (from what worked for others, and our own):**
- Only well-known sites. Skip any directory that looks spammy, and never pay
  for links or for a "submit to 100 directories" service: links from junk
  sites can count against us.
- Never name another booking platform in anything we write (owner's rule,
  22 Oct 2026).
- Same description everywhere (below), so the listings back each other up.

## 3. Communities (traffic and links, done carefully)

- **Reddit:** don't post ads. Answer questions where salon owners ask about
  booking, pricing, no-shows or price lists, and share the free tool that
  answers them (pricing calculator, price list maker, no-show policy). Read
  each community's rules on self-promotion first. Some need karma before
  you can post.
- **Get told when someone asks:** F5Bot (f5bot.com, free) emails you when a
  keyword turns up on Reddit or Hacker News. Suggested keywords:
  `salon booking software`, `booking app for salon`, `salon software australia`,
  `booking app monthly fee`, `salon price list template`,
  `how much to charge for lash`, `salon no show policy`.
- **Facebook groups for lash techs, nail techs and salon owners:** when
  someone asks what to charge or for a price list template, share the free
  tool. Tools get shared; ads get deleted.
- **Hacker News ("Show HN"), optional:** the audience is developers, so it
  rarely brings salon owners, but even a post that sinks leaves a strong link.
  Title idea: *Show HN: Booking software for salons that's paid once, not
  monthly*. Explain the one-off price and how it's built (no dependencies, one
  database file per business). Read their guidelines first.

## 4. After each new page

- In Search Console, use **URL Inspection → Request indexing** on new pages
  (about 10 a day are allowed). New on 26 Nov 2026:
  `/tools`, `/salon-pricing-calculator`, `/salon-price-list-maker`,
  `/instagram-booking-link`.
- The weekly run already pings IndexNow (Bing and others) for changed pages.

## Track it

Count new listings in `LOG.md` with the weekly run. Visits from each site show
in Lovable's analytics under sources.
